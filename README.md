# Mühür Dijital Davetiye

Mühür Dijital Davetiye; düğün, nişan ve özel günler için kurgusal örnek etkinliklerle hazırlanmış bir dijital davetiye demosudur.

## Geliştirme

Gereksinimler: Node.js ve Bun.

```sh
bun install
bun run dev
```

## Test

```sh
bun run test
```

Ürünler, etkinlik adları ve yönetim panelindeki siparişler yalnızca demo amaçlı kurgusal örneklerdir.
