# Mühür Dijital Davetiye

Mühür Dijital Davetiye; düğün, nişan ve özel günler için dijital davetiye tasarımlarını sergileyen bir mağaza demosudur. Ziyaretçiler katalogda tasarımları inceleyebilir, davetiye önizlemesini kişiselleştirebilir, ürünü hızlıca görüntüleyebilir ve sepet/ödeme akışını deneyebilir. Özel tasarım talebi gönderme bölümü de bulunur.

Ürünler ve etkinlik bilgileri demo amaçlı örneklerdir.

## Geliştirme

Gereksinimler: [Bun](https://bun.sh/)

```sh
bun install
bun run dev
```

Üretim derlemesi için `bun run build`, testler için `bun run test` komutlarını kullanın.
